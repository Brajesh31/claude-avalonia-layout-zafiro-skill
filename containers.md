# Semantic Containers

Use semantic containers to express layout intent rather than nesting generic panels without purpose.

## Guidelines
- Use a headered container when content has a meaningful title or header region.
- Use an edge panel for content anchored to a defined side of the available space.
- Use a card for a distinct, grouped unit of information or action.
- Keep container responsibilities small and avoid deeply nested cards.
- Ensure containers remain responsive when text grows or localization changes.

## Accessibility
Preserve logical reading order, keyboard navigation, focus indication, and meaningful automation names. Do not use visual grouping as a substitute for accessible labels.
