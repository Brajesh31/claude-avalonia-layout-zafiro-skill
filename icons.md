# Icons

Use the project's established icon extension and options consistently.

## Guidelines
- Prefer a shared icon catalog or typed identifiers over scattered raw glyphs.
- Set accessible names when an icon conveys information.
- Mark purely decorative icons as non-accessible to avoid duplicate announcements.
- Use consistent sizing, alignment, and stroke weight.
- Respect theme-aware foreground colors and disabled states.

Avoid using emoji or platform-dependent Unicode characters as production UI icons.
